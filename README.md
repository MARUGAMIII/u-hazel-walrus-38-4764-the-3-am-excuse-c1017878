A one-line excuse for make.fun's "The 3 AM Excuse" bounty ($2 in USDC). A hardware wallet with a grudge refuses to sign at 3 AM: it keeps a ledger, and the ledger says dog coin, 3 AM, four nights running — so tonight its button is on strike, its chip is dreaming, and the brain that wants the signature can clock back in at sunrise.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
